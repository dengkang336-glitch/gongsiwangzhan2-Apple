02 — Capabilities

One team, from design to launch

We do not outsource the core work. Direction, interface, engineering and launch happen in the same place, so decisions turn into working software quickly.

  • 01

    Native app engineeringSwiftUI · Swift · HealthKit · StoreKit

    Native work for iOS, iPadOS and watchOS: reading health data, in-app purchase and subscriptions, widgets, local notifications and localization. We have shipped 30 health metrics, store logic with both one-off and subscription products, and one interface in nine languages.

  • 02

    Web and real-time 3DTypeScript · React · Three.js · WebSocket

    Spaces you can walk into, in a browser: third-person navigation, shared scenes, PWA installation and touch controls. The performance budget is set for a mid-range phone, not a developer machine.

  • 03

    Product design and prototypesDesign system · Typography · Motion

    A prototype you can tap comes before interface code. A design system holds colour, type and spacing together; motion does a job rather than decorating. Direction is validated on a real device, not in imagination.

  • 04

    Privacy and local-first dataOn-device · No tracking · Minimal collection

    If it can be computed on the device, it is not uploaded: health, recordings, scans and documents stay local. Where a server is genuinely needed, the privacy policy says what is stored, where, and how to delete it.

  • 05

    Engineering and qualityUnit tests · Type checks · Self-check scripts

    Core logic has unit tests, key flows have end-to-end self-checks, and type checking is part of the build. Every product can be rebuilt and retested — it does not only run on one machine.
