02 — 能力

从设计到上线，一支队伍

我们不外包核心工作：产品方向、界面、工程与上线都在同一处完成，所以决定能很快变成可用的东西。

  • 01

    原生应用工程SwiftUI · Swift · HealthKit · StoreKit

    iOS、iPadOS 与 watchOS 的原生开发，包括健康数据读写、内购与订阅、小组件、本地通知与多语言本地化。我们做过 30 项健康指标、买断与订阅并存的商店逻辑，以及 9 种语言的同一套界面。

  • 02

    Web 与实时 3DTypeScript · React · Three.js · WebSocket

    在浏览器里做可以走进去的空间：第三人称漫游、多人同场、PWA 安装与移动端触屏操作。性能预算按中端手机定，而不是按开发机定。

  • 03

    产品设计与原型Design system · Typography · Motion

    先出可以点的原型，再写界面的代码。设计系统统一颜色、字号与间距；动效有实际作用，不只是装饰。方向在真机上验证，而不是在想象里验证。

  • 04

    隐私与本地优先On-device · No tracking · Minimal collection

    能在设备上算的就不上传：健康、录音、扫描、文档默认只留在本机。确实需要服务端的产品，会把存了什么、存在哪里、怎么删除写进隐私政策。

  • 05

    工程与质量Unit tests · Type checks · Self-check scripts

    核心逻辑有单元测试，关键流程有端到端自检，类型检查是构建的一部分。每个产品都能被重新构建、重新测试，而不是只在某台机器上能跑。

03 — 公司

关于云枢方舟

好的软件是被「做完」的，而不只是被「想出来」的。我们的工作信条

云枢方舟是一家以产品研发为核心的软件公司。我们把大部分时间花在自己的产品上：先找到真正的问题，再用尽量少的部件把它解决掉。

我们也接受定制开发：从需求梳理、可交互原型到原生开发与上线维护。合作方式写在公司页面里，报价按范围给出。
